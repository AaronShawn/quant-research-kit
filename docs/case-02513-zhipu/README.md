# 案例：港股智谱 02513.HK

选它做样例是因为它同时踩满了几个不利条件：**上市 8 个月、年化波动 186%、持续亏损、单月腰斩过半**。
在这种标的上，大部分量化模板会照常输出一整份数字；这套流程要演示的是**哪些模块会被拒绝输出**。

- 完整报告：[`report-02513-zhipu.html`](./report-02513-zhipu.html)（本地打开即可，图表为 ECharts）
- 行情截面：2026-09-24 收盘；财务数据为 2026 年中期业绩（2026-08-31 披露）

## 复现

```bash
python scripts/08_stock_probe.py --hk 02513 --bench HSI --horizons 1,3,5,10,20
```

`--bench` 不传不会报错，只是按表 F 静默跳过风险计量和归因分解两层。`--horizons` 默认是 `1,3,5,10`，不含 20 日。

## 报告里空着的两处

跑出来的第一件事是确认可信度等级：**176 个交易日 < 250 日门槛 → C 级**，报告里明确写了"仅可作量级参考"。

紧接着有两个模块直接空着不填：

| 模块 | 为什么不输出 |
|---|---|
| 形态统计胜率 | 四个形态的**独立波段数只有 1–3 个**（触发次数是 15/19/3/7），远低于表 E 要求的 8 个 |
| 「跌时波动更大」的判断 | GJR-GARCH 的杠杆项 γ 的 **p 值 = 0.859**，和 0 无法区分。α 也不显著（p=0.215），只有 β 显著（p=0.030） |

后一行牵涉到脚本本身的一个盲区 —— 它只打印参数值，不打印 t / p。这次是补跑了一段 `arch` 拟合才发现的。
样本短到这个程度时，**看不出杠杆效应 ≠ 不存在杠杆效应**，这两句话差得很远。

## 三个值得拎出来的判断

**1. β = 1.28 是一个没有信息量的数字。**
对恒指的相关系数只有 0.13，近 90 日 0.01，系统性波动占比 1.7%。这两个数放在一起的含义是 β 几乎解释不了任何东西。
过去两个月相对恒指跑输 71 个百分点，同期恒指还是涨的 —— 这部分亏损几乎全部来自融资摊薄、ZCode 数据风波这类**个股事件**，而不是板块回调。把它当 beta 回撤来抄底，归因从一开始就错了。

**2. 亏损「收窄」是会计口径造成的错觉。**
净亏损 23.58 → 20.72 亿（-12.1%），但经调整净亏损 17.52 → 19.64 亿（+12.1%）。差额来自上市后金融工具公允价值变动等非经营性项目。
毛利率 50.0% → 26.4% 也不是临时扰动，是收入结构从"一次性本地化授权"（占 84.8%）切换到"按 token 计费"（占 86.5%）的必然结果。
真正该盯的是经调整口径 + API 自身的毛利率爬坡（−0.4% → 24.6%）。

**3. 这类公司用 PS 估值会失真，用 ARR 才对得上。**
ROE −46.9%、PE 为负、净资产刚刚由负转正，以盈利或净资产为分母的比率全部失真。
唯一稳定的分母是可预期的经常性收入。按这个锚点，估值能不能消化完全取决于年末 ARR 指引能否兑现，与股价反弹无关。

## 这个案例往技能里加的四条经验

1. **GARCH 必须自己再看一遍显著性** —— 脚本不打印 t/p。见上文。
2. **`chg_ytd` 的基准是发行价，不是首日收盘价** —— 智谱两者分别给出 +449.5% 和 +385.6%，差 64 个百分点。
3. **四种 bootstrap 口径散得比想象中开** —— 未来 5 日上涨概率从 35.3%（近 60 日）到 55.9%（全历史），差 20.6 个百分点。样本期恰好是暴涨期时，"全历史"这一列的偏差最大。
4. **波动率分位要跑多窗口，但这次结论和上一次相反** —— 该股 20/60/120 日窗口分位分别是 0.6% / 8.6% / 5.4%，全部落在历史低位（此前在 MU 上遇到过 20 日 54.2% vs 250 日 95.1% 的反向情况）。**两个方向都可能，所以必须自己算，不能沿用上一次的结论。**
