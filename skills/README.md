# Skills

这三个技能是 AI Agent 可直接加载的 `SKILL.md`，**不含可执行代码，只含行为规范**。
真正干活的代码在同级的 `scripts/`。

## 怎么挂载

技能目录的放法因 Agent 而异，常见两种：

| 位置 | 作用域 |
|---|---|
| `~/.workbuddy/skills/<skill-name>/SKILL.md` | 用户级，所有项目可用 |
| `<项目>/.workbuddy/skills/<skill-name>/SKILL.md` | 项目级，仅该项目可用 |

把整个 `<skill-name>/` 目录复制过去即可，**不需要改任何内容**。

## 三个技能

### `quant-full-analysis` —— 九层分析编排

**触发**：用户说「量化分析 XXX」「分析一下这只股票」「X 的风险有多大」

**做什么**：自动跑完 L1 数据质量审计 → L2 描述与画像 → L3 时序建模 → L4 风险计量 →
L5 事件与条件 → L6 预测与区间 → L7 归因 → L8 外部信息 → L9 综合结论。

**核心资产是六张决策表**（见该文件 §3），它们规定「什么条件下说什么话」：

| 表 | 决定什么 |
|---|---|
| A | 样本量门控（<60 / 60–250 / 250–1000 / >1000 交易日各允许用哪些方法） |
| B | 漂移可识别性（`σ/√T` 检验后的分支措辞） |
| C | 预测口径（FHS 为主，三种 bootstrap 仅作对照） |
| D | 波动率状态（按历史分位而非绝对数值措辞） |
| E | 形态统计可用性（按独立波段数，而非触发次数） |
| F | 数据缺失降级路径 |

### `qlib-ashare-factor-research` —— A股因子研究流水线

**触发**：研究因子、跑股票池回测、诊断「回测净值很漂亮但信号其实无效」

**覆盖**：Qlib 数据格式的坑、Alpha158 + LightGBM + TopkDropout 端到端流程、
IC / ICIR / IR 的正确读法、独立复现与引擎口径对齐、涨跌停约束、生存者偏差。

### `quant-env-inventory` —— 环境盘点方法论

**触发**：「某个库装在哪」「venv 在哪」「数据源能不能通」「该用哪个解释器」

**覆盖**：找全解释器的四种方法、按领域归类包清单、**数据源可用性实测**（装得上 ≠ 连得通）、
七个高频坑（`ModuleNotFoundError` 的第一嫌疑、venv 不能移动、同名库版本陷阱等）。

## 四个设计原则

1. **一切自适应** —— 任何无条件输出的结论都视为 bug。方法选择、阈值、措辞全部由数据条件决定。
2. **能力门控** —— 每个方法声明最小样本要求，不满足就**整块不跑并注明原因**，
   而不是跑出一个打了折的数字。
3. **结论条件化** —— 每句话由条件表达式生成，不存在预写好的固定句子。
4. **降级而非崩溃** —— 缺基准就跳过相对强弱、缺财报就声明该层未覆盖，绝不静默失败。

## 不用 AI Agent 也能用

这些 `SKILL.md` 本身就是很好的**分析检查清单**：它们记录了每一类分析该看什么、
在什么条件下**不能**下什么结论。人工做研究时照着走一遍，可以避开大部分常见的统计陷阱。
